一份 JSON，打開自己的 MTG 牌組

匯入 Commander、60 張構築或其他自訂牌表；一樣能切換異圖、閃卡、記錄台灣店價和替換牌張。

不需要登入或架設伺服器。每次匯入都會新增一副牌組到「📚 牌組庫」，可隨時切換；修改會自動儲存在這個瀏覽器，HTML 改名也不影響。

本工具可離線開啟與編輯，但下載卡圖、查詢異圖／市場參考價需連上網路。資料來源：Scryfall。市場價格依版本、語言、一般／閃卡／刻蝕版本不同而異，且可能缺價。台幣為手動指定匯率估算，不是即時匯率。你可直接在每張卡片輸入台灣賣家實際報價，並即時查看相對於該印刷版本國外參考價的溢價或折價。所有牌組自動儲存在這個瀏覽器的牌組庫，與 HTML 檔名無關；建議使用 Chrome 或 Edge。換電腦、換瀏覽器或清除瀏覽資料會讀不到，請定期「匯出全部備份」。支援舊版 Indoraptor 編輯器 JSON 備份。圖片需網路。

編輯／替換牌張

在卡片上可直接勾選「已持有」、輸入台灣店價並查看國外價差；這個視窗主要用來搜尋替換牌張或修改數量。替換一疊基本地時，只會替換其中 1 張。

匯入牌組 JSON

請選擇 .json 檔，或貼入 JSON。匯入前會驗證格式，成功後會新增一副牌組到牌組庫，不會影響其他牌組。也可以匯入「匯出全部備份」產生的備份檔，一次還原所有牌組。

欄位：title 牌組名稱；format Commander / Standard / Modern / Custom；deck 陣列。每張牌最少填 name、qty、category；分類可使用「指揮官／生物／神器／結界／瞬間／巫術／地牌／鵬洛客」或英文類別。owned、manualNT、budgetNT、commanderColors 都是選填。可下載完整範本。

牌組設定

Commander 預設目標 100 張；構築格式預設至少 60 張。這裡只提示張數，不會攔阻自訂牌組。色組留空時不套用換牌的色組檢查；此工具不取代官方賽制合法性查詢。

📚 牌組庫

所有牌組都存在這個瀏覽器裡，跟 HTML 的檔名無關：這份 HTML 改名、搬位置都讀得到。換電腦、換瀏覽器或清除瀏覽資料之前，請先「匯出全部備份」，之後在新環境用「匯入 JSON／備份」還原。
